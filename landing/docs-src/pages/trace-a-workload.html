The profiler, `accelsim_trace.py`, runs a vLLM model on a Modal H100 under Accel-Sim's NVBit tracer and uploads each kernel's trace to your app's S3 endpoint as soon as that kernel finishes.

Use the streaming profiler from the `validate-accelsim-modal` branch (`accelsim_trace.py` at commit `b348d7d`). The copy at the root of the app branch is an older version that saves to a Modal Volume and has no `--s3-*` flags.

Set up Modal

The profiler runs on Modal. Install the client and log in once.

```bash pip install modal modal setup ```

The first run builds an image with NVBit, the tracer and vLLM, which takes a while. Later runs reuse it.

Pick the layers

Tracing every instruction is slow, so trace one or a few layers, not the whole model. List the layer names first.

```bash modal run accelsim_trace.py --model facebook/opt-125m --list-layers ```

Trace and stream

Pass the S3 endpoint that [Deploy the app](deploy.html) printed. The bucket is `cascade` and the endpoint needs path-style addressing.

```bash modal run accelsim_trace.py \ --model facebook/opt-125m \ --layers model.decoder.layers.10.self_attn \ --prompt "Hello, my name is" \ --max-tokens 4 \ --s3-endpoint https:// \ --s3-bucket cascade \ --s3-addressing-style path ```

Before it starts tracing, the profiler checks that the bucket is reachable and stops if it isn't. When it finishes, it prints where the trace went.

```text Done. Traces at s3://cascade/accelsim-traces/ ```

What gets uploaded

The tracer writes one `kernel--ctx_<0x..>.trace.xz` file per kernel and closes it before the next kernel starts. A background thread uploads each closed file and deletes it locally, so the Modal container only ever holds the kernel being traced plus any upload backlog.

After tracing ends, the profiler uploads the rest of the run: the logs, `metadata.json`, `spinlock_detection/spinlock_instructions.txt`, `traces/kernelslist_ctx_*` and `traces/stats_ctx_*`. It goes in sorted path order, so `metadata.json` arrives before the `traces/` files. It uploads them even when tracing failed, so a partial run is as complete as it can be. Everything lands under `s3://cascade/accelsim-traces//`.

`metadata.json` holds `model`, `layers`, `prompts`, `max_tokens`, `max_model_len`, `spinlock_handling`, `status` (`ok` or `failed`), `gpu` (from `nvidia-smi`), `accelsim_commit`, and upload counts. It doesn't set `trace_gpu_arch`, so the app uses its default `sm_90`, which is right for an H100.

The profiler doesn't post-process. The app runs Accel-Sim's post-processor once the upload is complete. See [Traces](traces.html).

The Modal function has 8 CPUs, 64 GiB of memory and 512 GiB of scratch disk, and times out after 4 hours. Tracing stops after 3.5 hours to leave time for uploads to drain.

Upload a trace you already have

`scripts/upload_trace.py` uploads a local directory with the same client settings as the profiler and sends `metadata.json` last, with `status` and a `files` list. Use `--meta key=value` to add fields such as `trace_gpu_arch` for a trace from another GPU. Values are strings.

```bash uv run python scripts/upload_trace.py ./my-run --run-name my-run \ --endpoint https:// --meta trace_gpu_arch=sm_80 ```

Add `--status failed` to mark the upload as failed. The app then marks the trace `failed` without processing it.

Profile, trace and simulate in your own Modal app

See the [OPT-125m sample analysis](sample-analysis-opt125m.html) for measured pipeline costs, kernel and request replay errors, coverage, and limitations of an existing run.

Install with `pip install "git+https://github.com/atoniolo76/cascade@profiler"`, using Python 3.12 locally because `register()` uses serialized Modal functions.

`prof.profile` runs on GPU: baseline (no profiler), nsys capture, then NVBit tracing of the chosen steps, writing `corrected_timeline.json` and `trace_alignment.json`.

`prof.simulate` runs Accel-Sim on CPU and writes `sim_durations.json`.

```python # app.py import modal from cascade_profiler import Workload, register app = modal.App("my-profiler") runs = modal.Volume.from_name("my-profiler-runs", create_if_missing=True) hf = modal.Volume.from_name("my-hf-cache", create_if_missing=True) prof = register(app, runs, gpu="H100!", hf_cache=hf) @app.local_entrypoint() def main(): wl = Workload("facebook/opt-125m", ["Hello, my name is"], max_tokens=32, repeats=4) run = prof.profile.remote(wl.to_dict(), trace_steps=[0, 5]) # GPU: baseline -> nsys -> NVBit on steps 0,5 sim = prof.simulate.remote(run["run_name"], verify_dedup=2) # CPU: Accel-Sim on the traced kernels print(run["run_name"], run["stage_wall_s"], sim["coverage"]) ```

Run with `modal run app.py`, then download with `modal volume get my-profiler-runs ./`.
