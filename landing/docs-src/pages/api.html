Everything the UI does goes through this HTTP API. It serves JSON over the app's URL, the one `deploy_sail.py` prints as `app:`.

Every response on these pages was captured from a running server, by `landing/docs-src/capture_examples.py`. The sims in that run replayed a recorded Accel-Sim log of BabelStream on an RTX 3070, so the cycles, IPC and kernel names come from that log, not from the uploaded trace. Long lists and maps are trimmed, and each cut is marked with a `/* ... trimmed */` comment.

Base URL

The samples read the app's URL and your token from the environment.

```bash export CASCADE_URL=https:// export CASCADE_TOKEN= ```

Locally, the app's URL is `http://127.0.0.1:8000`.

Authentication

Send the token the app was started with as a bearer token on every request.

```bash curl -H "Authorization: Bearer $CASCADE_TOKEN" "$CASCADE_URL/api/traces" ```

A missing or wrong token gets `401` with a `WWW-Authenticate: Bearer` header. Two routes differ.

  • [Check health](#health) needs no token.
  • [Stream run events](api-events.html#run-events) also accepts the token as `?token=`, because the browser's `EventSource` can't send headers.

There is one token per app, shared by the UI, the profiler and every sim. The app compares it in constant time.

Conventions

  • Request and response bodies are JSON. Every [type](types.html) is generated from `cascade/models.py`.
  • Timestamps are ISO 8601 in UTC, such as `2026-11-08T03:05:34.001386Z`.
  • A trace's id is the profiler's run name. Runs and sims get generated ids, `run-` or `sim-` and 12 hex digits.
  • Lists come back whole. There is no pagination.
  • Errors are JSON with a `detail` field. See [Errors](errors.html).
