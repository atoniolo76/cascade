API reference

Traces

Traces arrive over S3, not over this API. These routes read what the app has registered. To add a trace, upload it to the S3 endpoint as described in Trace a workload.

List traces#

GET/api/tracesbearer token

Lists every trace the app has registered, in every state, newest first by created_at. A trace appears as soon as its first file lands in the bucket, so this list also shows uploads in progress.

Returns#

200 with a list of TraceSummary.

Errors#

statuswhen
401The Authorization header is missing, is not Bearer <token>, or the token is wrong.

Example#

bash
curl "$CASCADE_URL/api/traces" \
  -H "Authorization: Bearer $CASCADE_TOKEN"
python
import os

import httpx

headers = {"Authorization": f"Bearer {os.environ['CASCADE_TOKEN']}"}
resp = httpx.get(f"{os.environ['CASCADE_URL']}/api/traces", headers=headers)
resp.raise_for_status()
print(resp.json())
js
const resp = await fetch(`${CASCADE_URL}/api/traces`, {
  headers: { Authorization: `Bearer ${CASCADE_TOKEN}` },
});
console.log(await resp.json());

Get a trace#

GET/api/traces/{trace_id}bearer token

Returns one trace with the parsed metadata.json and every kernel launch read from the trace's stats_ctx_* files. kernels stays empty until the trace is ready.

Path parameters#

nametypedescription
trace_idstrThe trace's id, which is the profiler's run name.

Returns#

200 with a TraceDetail.

Errors#

statuswhen
401The Authorization header is missing, is not Bearer <token>, or the token is wrong.
404No trace has this id.

Example#

bash
curl "$CASCADE_URL/api/traces/demo" \
  -H "Authorization: Bearer $CASCADE_TOKEN"
python
import os

import httpx

headers = {"Authorization": f"Bearer {os.environ['CASCADE_TOKEN']}"}
resp = httpx.get(f"{os.environ['CASCADE_URL']}/api/traces/demo", headers=headers)
resp.raise_for_status()
print(resp.json())
js
const resp = await fetch(`${CASCADE_URL}/api/traces/demo`, {
  headers: { Authorization: `Bearer ${CASCADE_TOKEN}` },
});
console.log(await resp.json());
