API reference

Runs

A run simulates one ready trace on a list of GPU configs. These routes create and cancel runs, read their sims, and download what the sims produced. Runs covers the same ground as a guide.

List GPU configs#

GET/api/gpu-configsbearer token

Lists the GPU configs the app found at startup under $CASCADE_ACCELSIM_DIR/gpu-simulator/gpgpu-sim/configs/tested-cfgs/*/gpgpusim.config. The app derives arch from the directory name (SM90_H100 is sm_90, SM7_QV100 is sm_70) and reads core_clock_mhz from the first value of -gpgpu_clock_domains. A directory whose name or clock it can't read is skipped.

Returns#

200 with a list of GpuConfig, sorted by name.

Errors#

statuswhen
401The Authorization header is missing, is not Bearer <token>, or the token is wrong.

Create a run#

POST/api/runsbearer token

Creates a run and starts launching its sims in the background. Each entry fans out to count sims, numbered by replica from 0. The response comes back before any sim has launched, so every sim is pending or launching. Follow progress with Stream run events or by polling Get a run.

Request body#

JSON, RunCreate.

fieldtypedescription
trace_idstrA trace in state ready.
entrieslist[RunEntry]One entry per config. Each fans out to count sims. at least 1 item

Each RunEntry has these fields.

fieldtypedescription
gpu_configstrA GpuConfig.name whose arch matches the trace's trace_gpu_arch.
countintHow many sims run this config. at least 1, at most 64

Returns#

201 with a RunDetail.

Errors#

statuswhen
401The Authorization header is missing, is not Bearer <token>, or the token is wrong.
404trace_id names no trace.
409The trace is not ready, or is a sample, which has no instruction traces.
422An entry names an unknown gpu_config, or a config whose arch differs from the trace's trace_gpu_arch.
422The body fails validation: entries is empty, or a count is outside 1 to 64.

Example#

bash
curl -X POST "$CASCADE_URL/api/runs" \
  -H "Authorization: Bearer $CASCADE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"trace_id": "demo", "entries": [{"gpu_config": "SM86_RTX3070", "count": 2}]}'
python
import os

import httpx

headers = {"Authorization": f"Bearer {os.environ['CASCADE_TOKEN']}"}

Cancel a run#

POST/api/runs/{run_id}/cancelbearer token

Moves every sim that has not finished to cancelled and asks the launcher to stop it. Sims that already finished keep their state. The next heartbeat from a cancelled sim gets cancel: true. Calling it again changes nothing, so it is safe to retry. On a sample run it changes nothing either, since its sim already succeeded.

Path parameters#

nametypedescription
run_idstrThe run's id, such as run-9f56e171af08.

Returns#

200 with the RunDetail after cancelling.

Errors#

statuswhen
401The Authorization header is missing, is not Bearer <token>, or the token is wrong.

List a run's step timing#

GET/api/runs/{run_id}/step-timelinesbearer token

Returns a SimStepTimeline for every sim in the run that has sent step timing, ordered by config, then replica. A sim sends one after it succeeds on a trace whose has_step_timeline is true, so the list is empty until then, and stays empty for other traces. simulated is a full simulated_timeline.json, with every kernel of every step, so for a real model it can be several megabytes per sim. Per-kind step means are in simulated.summary.per_kind, coverage is in simulated.summary.simulation.coverage, and per-step and per-request errors against the real run are in compare.

Download run results#

GET/api/runs/{run_id}/resultsbearer token

Returns everything about a run as one JSON download, with Content-Disposition: attachment; filename="<run_id>-results.json". Each sim's kernels carry the full stats map, every key = value line Accel-Sim printed for that kernel, which is about 30 KB per kernel.

Path parameters#

nametypedescription
run_idstrThe run's id, such as run-9f56e171af08.

Returns#

200 with a RunResults.

Errors#

statuswhen
401The Authorization header is missing, is not Bearer <token>, or the token is wrong.
404No run has this id.

Example#

bash
curl -OJ "$CASCADE_URL/api/runs/run-210d75c008c4/results" \
  -H "Authorization: Bearer $CASCADE_TOKEN"
