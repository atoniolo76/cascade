API reference

Runs

A run simulates one ready trace on a list of GPU configs. These routes create and cancel runs, read their sims, and download what the sims produced. Runs covers the same ground as a guide.

List GPU configs#

GET/api/gpu-configsbearer token

Lists the GPU configs the app found at startup under $CASCADE_ACCELSIM_DIR/gpu-simulator/gpgpu-sim/configs/tested-cfgs/*/gpgpusim.config. The app derives arch from the directory name (SM90_H100 is sm_90, SM7_QV100 is sm_70) and reads core_clock_mhz from the first value of -gpgpu_clock_domains. A directory whose name or clock it can't read is skipped.

Returns#

200 with a list of GpuConfig, sorted by name.

Errors#

statuswhen
401The Authorization header is missing, is not Bearer <token>, or the token is wrong.

Example#

bash
curl "$CASCADE_URL/api/gpu-configs" \
  -H "Authorization: Bearer $CASCADE_TOKEN"
python
import os

import httpx

headers = {"Authorization": f"Bearer {os.environ['CASCADE_TOKEN']}"}
resp = httpx.get(f"{os.environ['CASCADE_URL']}/api/gpu-configs", headers=headers)
resp.raise_for_status()
print(resp.json())
js
const resp = await fetch(`${CASCADE_URL}/api/gpu-configs`, {
  headers: { Authorization: `Bearer ${CASCADE_TOKEN}` },
});
console.log(await resp.json());

Create a run#

POST/api/runsbearer token

Creates a run and starts launching its sims in the background. Each entry fans out to count sims, numbered by replica from 0. The response comes back before any sim has launched, so every sim is pending or launching. Follow progress with Stream run events or by polling Get a run.

Request body#

JSON, RunCreate.

fieldtypedescription
trace_idstrA trace in state ready.
entrieslist[RunEntry]One entry per config. Each fans out to count sims. at least 1 item

Each RunEntry has these fields.

fieldtypedescription
gpu_configstrA GpuConfig.name whose arch matches the trace's trace_gpu_arch.
countintHow many sims run this config. at least 1, at most 64

Returns#

201 with a RunDetail.

Errors#

statuswhen
401The Authorization header is missing, is not Bearer <token>, or the token is wrong.
404trace_id names no trace.
409The trace is not ready.
422An entry names an unknown gpu_config, or a config whose arch differs from the trace's trace_gpu_arch.
422The body fails validation: entries is empty, or a count is outside 1 to 64.

Example#

bash
curl -X POST "$CASCADE_URL/api/runs" \
  -H "Authorization: Bearer $CASCADE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"trace_id": "demo", "entries": [{"gpu_config": "SM86_RTX3070", "count": 2}]}'
python
import os

import httpx

headers = {"Authorization": f"Bearer {os.environ['CASCADE_TOKEN']}"}
resp = httpx.post(f"{os.environ['CASCADE_URL']}/api/runs", headers=headers, json={"trace_id": "demo", "entries": [{"gpu_config": "SM86_RTX3070", "count": 2}]})
resp.raise_for_status()
print(resp.json())
js
const resp = await fetch(`${CASCADE_URL}/api/runs`, {
  method: "POST",
  headers: { Authorization: `Bearer ${CASCADE_TOKEN}`, "Content-Type": "application/json" },
  body: JSON.stringify({"trace_id": "demo", "entries": [{"gpu_config": "SM86_RTX3070", "count": 2}]}),

Cancel a run#

POST/api/runs/{run_id}/cancelbearer token

Moves every sim that has not finished to cancelled and asks the launcher to stop it. Sims that already finished keep their state. The next heartbeat from a cancelled sim gets cancel: true. Calling it again changes nothing, so it is safe to retry.

Path parameters#

nametypedescription
run_idstrThe run's id, such as run-d96aefcba965.

Returns#

200 with the RunDetail after cancelling.

Errors#

statuswhen
401The Authorization header is missing, is not Bearer <token>, or the token is wrong.
404No run has this id.

Example#

bash
curl -X POST "$CASCADE_URL/api/runs/run-06e0e1ec00a9/cancel" \
  -H "Authorization: Bearer $CASCADE_TOKEN"
python
import os

import httpx

headers = {"Authorization": f"Bearer {os.environ['CASCADE_TOKEN']}"}
resp = httpx.post(f"{os.environ['CASCADE_URL']}/api/runs/run-06e0e1ec00a9/cancel", headers=headers)
resp.raise_for_status()
print(resp.json())
js

Compare real and simulated time#

GET/api/runs/{run_id}/comparisonbearer token

Lines up kernels by order. Row i holds the ith kernel the sims finished and the ith row of the trace's real timing, sorted by kernel_id. For each config, sim_ns is the median sim_time_ns over that config's replicas, or null if no replica has finished that kernel. real_ns is null until the trace has real timing, which the profiler does not capture yet.

Path parameters#

nametypedescription
run_idstrThe run's id, such as run-d96aefcba965.

Returns#

200 with a Comparison.

Errors#

statuswhen
401The Authorization header is missing, is not Bearer <token>, or the token is wrong.
404No run has this id.

Example#

bash
curl "$CASCADE_URL/api/runs/run-d96aefcba965/comparison" \
  -H "Authorization: Bearer $CASCADE_TOKEN"
python
import os

import httpx

resp.raise_for_status()
print(resp.json())

Download run results#

GET/api/runs/{run_id}/resultsbearer token

Returns everything about a run as one JSON download, with Content-Disposition: attachment; filename="<run_id>-results.json". Each sim's kernels carry the full stats map, every key = value line Accel-Sim printed for that kernel, which is about 30 KB per kernel.

Path parameters#

nametypedescription
run_idstrThe run's id, such as run-d96aefcba965.

Returns#

200 with a RunResults.

Errors#

statuswhen
401The Authorization header is missing, is not Bearer <token>, or the token is wrong.
404No run has this id.

Example#

bash
curl -OJ "$CASCADE_URL/api/runs/run-d96aefcba965/results" \
  -H "Authorization: Bearer $CASCADE_TOKEN"
python
import os

import httpx

headers = {"Authorization": f"Bearer {os.environ['CASCADE_TOKEN']}"}
resp = httpx.get(f"{os.environ['CASCADE_URL']}/api/runs/run-d96aefcba965/results", headers=headers)
resp.raise_for_status()
open("run-d96aefcba965-results.json", "wb").write(resp.content)

Download sim results#

GET/api/sims/{sim_id}/resultsbearer token

Returns one sim's results as a JSON download named <sim_id>-results.json. totals is the sim's latest SimMetrics.

Path parameters#

nametypedescription
sim_idstrThe sim's id, such as sim-45609b32f314. Find it in RunDetail.sims.

Returns#

200 with a SimResults.

Errors#

statuswhen
401The Authorization header is missing, is not Bearer <token>, or the token is wrong.
404No sim has this id.

Example#

bash
curl -OJ "$CASCADE_URL/api/sims/sim-45609b32f314/results" \
  -H "Authorization: Bearer $CASCADE_TOKEN"
python
import os

import httpx

headers = {"Authorization": f"Bearer {os.environ['CASCADE_TOKEN']}"}
resp = httpx.get(f"{os.environ['CASCADE_URL']}/api/sims/sim-45609b32f314/results", headers=headers)
resp.raise_for_status()
open("sim-45609b32f314-results.json", "wb").write(resp.content)
js
const resp = await fetch(`${CASCADE_URL}/api/sims/sim-45609b32f314/results`, {
  headers: { Authorization: `Bearer ${CASCADE_TOKEN}` },
});

Download a sim's log#

GET/api/sims/{sim_id}/logbearer token

Streams every line the simulator sent, in seq order, as text/plain named <sim_id>.log.

Path parameters#

nametypedescription
sim_idstrThe sim's id, such as sim-45609b32f314. Find it in RunDetail.sims.

Returns#

200 with the log as plain text.

Errors#

statuswhen
401The Authorization header is missing, is not Bearer <token>, or the token is wrong.
404No sim has this id.

Example#

bash
curl -OJ "$CASCADE_URL/api/sims/sim-45609b32f314/log" \
  -H "Authorization: Bearer $CASCADE_TOKEN"
python
import os

import httpx

headers = {"Authorization": f"Bearer {os.environ['CASCADE_TOKEN']}"}
resp = httpx.get(f"{os.environ['CASCADE_URL']}/api/sims/sim-45609b32f314/log", headers=headers)
resp.raise_for_status()
open("sim-45609b32f314.log", "w").write(resp.text)
js
const resp = await fetch(`${CASCADE_URL}/api/sims/sim-45609b32f314/log`, {

});
