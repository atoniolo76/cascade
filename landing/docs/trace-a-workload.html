Guides

Trace a workload

The profiler, accelsim_trace.py, runs a vLLM model on a Modal H100 under Accel-Sim's NVBit tracer and uploads each kernel's trace to your app's S3 endpoint as soon as that kernel finishes.

Use the streaming profiler from the validate-accelsim-modal branch (accelsim_trace.py at commit b348d7d). The copy at the root of the app branch is an older version that saves to a Modal Volume and has no --s3-* flags.

Set up Modal#

The profiler runs on Modal. Install the client and log in once.

bash
pip install modal
modal setup

The first run builds an image with NVBit, the tracer and vLLM, which takes a while. Later runs reuse it.

Pick the layers#

Tracing every instruction is slow, so trace one or a few layers, not the whole model. List the layer names first.

bash
modal run accelsim_trace.py --model facebook/opt-125m --list-layers

Trace and stream#

Pass the S3 endpoint that Deploy the app printed. The bucket is cascade and the endpoint needs path-style addressing.

bash
modal run accelsim_trace.py \
  --model facebook/opt-125m \
  --layers model.decoder.layers.10.self_attn \
  --prompt "Hello, my name is" \
  --max-tokens 4 \
  --s3-endpoint https://<your-s3-endpoint> \
  --s3-bucket cascade \
  --s3-addressing-style path

Before it starts tracing, the profiler checks that the bucket is reachable and stops if it isn't. When it finishes, it prints where the trace went.

text
Done. Traces at s3://cascade/accelsim-traces/<run name>

What gets uploaded#

The tracer writes one kernel-<N>-ctx_<0x..>.trace.xz file per kernel and closes it before the next kernel starts. A background thread uploads each closed file and deletes it locally, so the Modal container only ever holds the kernel being traced plus any upload backlog.

After tracing ends, the profiler uploads the rest of the run: the logs, metadata.json, spinlock_detection/spinlock_instructions.txt, traces/kernelslist_ctx_* and traces/stats_ctx_*. It goes in sorted path order, so metadata.json arrives before the traces/ files. It uploads them even when tracing failed, so a partial run is as complete as it can be. Everything lands under s3://cascade/accelsim-traces/<run name>/.

metadata.json holds model, layers, prompts, max_tokens, max_model_len, spinlock_handling, status (ok or failed), gpu (from nvidia-smi), accelsim_commit, and upload counts. It doesn't set trace_gpu_arch, so the app uses its default sm_90, which is right for an H100.

The profiler doesn't post-process. The app runs Accel-Sim's post-processor once the upload is complete. See Traces.

Profiler flags#

flagdefaultwhat it sets
--modelfacebook/opt-125mThe Hugging Face model vLLM loads.
--layersmodel.decoder.layers.10.self_attnComma-separated module names to trace.
--promptHello, my name isThe one prompt to generate from.
--max-tokens4Tokens to generate. Each token is another forward pass to trace.
--max-model-len2048vLLM's max_model_len.
--run-nametime, model and layersThe trace's id in Cascade. The default looks like 20261107-120000__facebook_opt-125m__model.decoder.layers.10.self_attn.
--list-layersoffPrint layer names and exit without tracing.
--spinlock-handlingmark_regionmark_region, fast_forward or none. Any mode but none first runs Accel-Sim's two-pass spinlock detection.
--s3-endpointnoneYour app's S3 endpoint.
--s3-bucketnone, requiredUse cascade.
--s3-prefixaccelsim-tracesMust match the app's CASCADE_S3_PREFIX.
--s3-regionautoRegion name for the S3 client.
--s3-addressing-styleautoUse path for the Cascade endpoint.

The Modal function has 8 CPUs, 64 GiB of memory and 512 GiB of scratch disk, and times out after 4 hours. Tracing stops after 3.5 hours to leave time for uploads to drain.

Upload a trace you already have#

scripts/upload_trace.py uploads a local directory with the same client settings as the profiler and sends metadata.json last, with status and a files list. Use --meta key=value to add fields such as trace_gpu_arch for a trace from another GPU. Values are strings.

bash
uv run python scripts/upload_trace.py ./my-run --run-name my-run \
  --endpoint https://<your-s3-endpoint> --meta trace_gpu_arch=sm_80

Add --status failed to mark the upload as failed. The app then marks the trace failed without processing it.
