API reference

Simulator endpoints

A simulator makes two calls: a heartbeat every few seconds, and a log chunk whenever it has output. Both are safe to retry. Bring your own simulator puts them together into a working client.

Send a heartbeat#

POST/api/sims/{sim_id}/heartbeatbearer token

Records that the sim is alive and, if state differs, moves the sim to it when SIM_TRANSITIONS allows the move. A running heartbeat brings a lost sim back. A heartbeat for a sim that already finished changes nothing and returns its final state. Send one every few seconds. A sim with no heartbeat for CASCADE_HEARTBEAT_TIMEOUT_S (60 by default) becomes lost.

Path parameters#

nametypedescription
sim_idstrThe sim's id, such as sim-45609b32f314. Find it in RunDetail.sims.

Request body#

JSON, Heartbeat.

fieldtypedescription
stateLiteral["running", "succeeded", "failed"]What the simulator reports. Send running while working and succeeded or failed once at the end.
exit_codeint | NoneYour process's exit code. Send it with the final heartbeat. default null
errorstr | NoneA short reason, with a failed heartbeat. default null

Returns#

200 with a HeartbeatAck. If cancel is true, stop simulating and exit.

Errors#

statuswhen
401The Authorization header is missing, is not Bearer <token>, or the token is wrong.
404No sim has this id.
422state is not running, succeeded or failed.

Example#

bash
curl -X POST "$CASCADE_URL/api/sims/sim-45609b32f314/heartbeat" \
  -H "Authorization: Bearer $CASCADE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"state": "running"}'
python
import os

import httpx

headers = {"Authorization": f"Bearer {os.environ['CASCADE_TOKEN']}"}
resp = httpx.post(f"{os.environ['CASCADE_URL']}/api/sims/sim-45609b32f314/heartbeat", headers=headers, json={"state": "running"})
resp.raise_for_status()
print(resp.json())
js
const resp = await fetch(`${CASCADE_URL}/api/sims/sim-45609b32f314/heartbeat`, {
  method: "POST",
  headers: { Authorization: `Bearer ${CASCADE_TOKEN}`, "Content-Type": "application/json" },
  body: JSON.stringify({"state": "running"}),
});
console.log(await resp.json());

Send log lines#

POST/api/sims/{sim_id}/logsbearer token

Appends lines to the sim's log and parses any finished Accel-Sim kernel blocks out of them. Number chunks from 0 and add one each time. The app stores the first chunk it gets for each seq and ignores repeats, so a retry after a timeout is safe. Send lines without their trailing newline.

Path parameters#

nametypedescription
sim_idstrThe sim's id, such as sim-45609b32f314. Find it in RunDetail.sims.

Request body#

JSON, LogChunk.

fieldtypedescription
seqintPer-sim, increasing; a repeated seq is ignored. at least 0
lineslist[str]Lines of simulator stdout, without trailing newlines.

Returns#

204 with no body, whether the chunk was new or a repeat.

Errors#

statuswhen
401The Authorization header is missing, is not Bearer <token>, or the token is wrong.
404No sim has this id.
422seq is negative or lines is not a list of strings.

Example#

bash
curl -X POST "$CASCADE_URL/api/sims/sim-45609b32f314/logs" \
  -H "Authorization: Bearer $CASCADE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"seq": 0, "lines": ["replayed line"]}'
python
import os

import httpx

headers = {"Authorization": f"Bearer {os.environ['CASCADE_TOKEN']}"}
resp = httpx.post(f"{os.environ['CASCADE_URL']}/api/sims/sim-45609b32f314/logs", headers=headers, json={"seq": 0, "lines": ["replayed line"]})
resp.raise_for_status()
js
const resp = await fetch(`${CASCADE_URL}/api/sims/sim-45609b32f314/logs`, {
  method: "POST",
  headers: { Authorization: `Bearer ${CASCADE_TOKEN}`, "Content-Type": "application/json" },
