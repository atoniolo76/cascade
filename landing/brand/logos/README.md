# Brand logos

Real company and project logos, used wherever Cascade names a product, model family or GPU vendor. `logos.json` lists each logo's files and source, and how to match a Hugging Face model id or a GPU name to a logo.

- `<key>.svg` is the full-color logo, when one exists. `<key>-mono.svg` uses `currentColor`.
- Sources are pinned: `@lobehub/icons-static-svg@1.100.0` (MIT) and `simple-icons@13.21.0` (CC0). The Sail logo comes from docs.sailresearch.com.
- These logos are the trademarks of their owners. Use them only to refer to those products.
