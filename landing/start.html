Your own Cascade app, running in your Sail account. Name a workspace, paste a Sail API key, and it is up in a few minutes. Nothing to clone.

1 · create a workspace

What the key is used for.
  • Used once to create your workspace in your Sail account.
  • Not stored by Cascade. This page keeps it in memory only, and our server forgets it after each request.
  • Placed in your workspace so it can fork simulators.

The workspace runs on your Sail bill. Sail charges for the CPU, memory and disk it actually uses (Sail pricing). Auto-sleep is off for now, so it keeps running until you pause it under Manage.
