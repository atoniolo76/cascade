How we handle your key
  • This page holds it in memory only. Reloading the tab clears it.
  • Cascade's server uses it for one call to Sail per request and keeps nothing.
  • It is copied into your workspace, which needs it to start a Sail sandbox for each simulator.

The workspace bills to your Sail account for the CPU, memory and disk it uses (Sail pricing). It doesn't sleep on its own yet, so pause it when you're done.
